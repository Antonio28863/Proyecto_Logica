# Proyecto_Logica
Resolución de los ejercicios sobre lógica consultas SQL.

# Descripción
En este proyecto se resuelven los ejercicios planteados de consultas SQL realizadas sobre la base de datos Sakila.
Se ha utilizado Postgres y DBeaver.
En él se demuestran las capacidades obtenidas sobre:
- Manejo de la herramienta DBeaver.
- Manejo de las consultas con una sola tabla de la BBDD.
- Manejo de las relaciones entre tablas.
- Manejo de las subconsultas.
- Vistas.
- Estructuras de datos temporales.
- Buenas prácticas.
